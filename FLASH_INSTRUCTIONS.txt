==============================================================================
  OUI SPY UNIFIED BLUE -- Flash Instructions
  Board: Heltec WiFi LoRa 32 V4  (ESP32-S3, 16 MB flash, 2 MB PSRAM)
==============================================================================

  WHAT'S IN THE BOX
  -----------------
  flash.py              Flasher script (Python 3)
  requirements.txt      Python dependencies
  firmware-heltec/
    bootloader.bin      ESP32-S3 bootloader         (0x0000)
    partitions.bin      Partition table              (0x8000)
    boot_app0.bin       OTA data                     (0xe000)
    oui-spy-unified-blue.bin  Application firmware   (0x10000)


  SETUP (one time)
  ----------------
  1. Install Python 3.8+ from https://www.python.org
     - Windows: check "Add Python to PATH" during install
     - Linux:   sudo apt install python3 python3-pip
     - macOS:   brew install python3

  2. Install Python dependencies:

     pip install -r requirements.txt


  FLASH ONE BOARD
  ---------------
  1. Plug in the Heltec WiFi LoRa 32 V4 via USB-C (data cable, not charge-only)
  2. Run:

     python flash.py

  3. Confirm when prompted
  4. Wait for "Done!" -- board reboots automatically


  FLASH MANY BOARDS (batch mode)
  ------------------------------
  1. Run:   python flash.py --batch
  2. Plug in a board, it auto-detects and flashes
  3. Watch the OLED light up with the selector screen = success
  4. Swap boards; repeat. Press Ctrl+C when finished.

  To erase flash before writing (clean slate):

     python flash.py --batch --erase


  VERIFYING A FLASHED BOARD
  -------------------------
  1. The OLED shows "OUI-SPY" and "Mode: SELECTOR" -- if the screen lights up,
     the firmware is running.  (There is no on-board buzzer, so no boot beeps.)
  2. A WiFi AP appears: SSID "oui-spy" / password "ouispy123"
  3. Connect and open http://192.168.4.1 -- the mode selector dashboard.


  TROUBLESHOOTING
  ---------------
  "No ESP32 detected"
    - Check the USB cable is a data cable (not charge-only)
    - Try a different USB port

  "esptool not found"
    - Run: pip install esptool pyserial

  Blank OLED / no AP after flash
    - Make sure all 4 .bin files are in firmware-heltec/
    - Try: python flash.py --erase   (full erase first)

  Permission denied on serial port
    - Linux: sudo usermod -a -G dialout $USER  (then log out/in)
    - macOS: should work out of the box


  BUILDING FROM SOURCE
  --------------------
  Requires PlatformIO. The board is an ESP32-S3, built on the standard
  espressif32 (Arduino core 2.x) platform -- no special toolchain.

     pio run -t upload            # build + flash directly (simplest)

  Or copy the build artifacts into firmware-heltec/ and use flash.py:

     pio run
     cp .pio/build/heltec_wifi_lora_32_v4/bootloader.bin firmware-heltec/
     cp .pio/build/heltec_wifi_lora_32_v4/partitions.bin firmware-heltec/
     cp .pio/build/heltec_wifi_lora_32_v4/firmware.bin    firmware-heltec/oui-spy-unified-blue.bin
     find ~/.platformio/packages -path '*framework-arduinoespressif32*tools/partitions/boot_app0.bin' | head -1 | xargs -I{} cp {} firmware-heltec/
     python flash.py
